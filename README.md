# Project overviews

Overviews of my projects: what each one is for, what it does, and how it looks in use.

| Project | What it is | Repo |
|---|---|---|
| [Aggre/Gator](aggre-gator/README.md) | An event aggregator: groups related events from HTTP and SNMP sources by key, follows each group from first event to last, and flags the ones that never finish | [Public](https://github.com/chrisnock-personal/eventagg) |
| [Alfoir](alfoir/README.md) | A platform for running checks and scripts on a schedule, from the server or agents, with results, telemetry, alerts and a status page; tests websites, hosts, APIs and, with CallRaven, phone systems | Private |
| [Branchwarden](branchwarden/README.md) | Watches the pull requests and branches across a GitHub organisation or account: what each PR is waiting on, stale and left-behind branches, reviewers requested by hand or automatically, review metrics, a weekly MVP board, and reminders in Teams or Slack | [Public](https://github.com/chrisnock-personal/branchwarden) |
| [CallNest](callnest/README.md) | A call recorder built on open standards: captures calls from Asterisk, SIPREC, SIP or a packet capture, then transcribes, checks and seals them | Private |
| [CallOwl](callowl/README.md) | A self-hosted call logging platform: collects Open CDR call records from any phone system, then searches, measures and audits them with scoped access | Private |
| [CallRaven](callraven/README.md) | A containerised SIP softphone and test tool for phone systems: real calls, captured, measured, transcribed and graded, from a web UI or a REST API | Private |
| [CallRoost](callroost/README.md) | The tester of testers: a test platform for compliance capture and telephony tools, built on a phone system with known answers. IVRs, a contact centre and about 40 numbers that fail on purpose, each with the CDRs, Open CDR record, recording and SIPREC session it should leave, worked out in advance and checked against real calls | Private |
| [Desktop Icon Manager](desktop-icon-manager/README.md) | A native Linux app for changing any application's icon in the menu and dock, Chrome web apps included | [Public](https://github.com/chrisnock-personal/desktop-icon-manager) |
| [FleetWright](fleetwright/README.md) | Keeps Linux servers up to date, through an agent or over SSH: what's pending across the fleet, installs in batches with a canary, auto-install policies by kind of update, booked maintenance windows, and a record of every package changed | [Public](https://github.com/chrisnock-personal/fleetwright) |
| [Parley](parley/README.md) | An IP intercom in the browser: talk groups and direct calls, with live transcripts, group chat and SIP-REC recording | Private |
| [Skyfarer](skyfarer/README.md) | Watches the status pages of nine cloud providers, from AWS and Azure to DigitalOcean and Hetzner, and tells you about incidents and maintenance in the regions you run in, through Zendesk, ServiceNow, Jira Service Management, Freshdesk, PagerDuty, Pushover, Teams, SNMP traps or webhooks, all set up in the browser | [Public](https://github.com/chrisnock-personal/skyfarer) |
| [The Open CDR Project](open-cdr/README.md) | An open, vendor-neutral standard for call detail records: one record shape for every call, whichever phone system made it, and one API to read them | [Public](https://github.com/chrisnock-personal/open-cdr-project) |
